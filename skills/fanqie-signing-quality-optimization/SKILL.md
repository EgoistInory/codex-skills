# 番茄小说签约质量改进优化调教原则规范

本规范旨在解决番茄小说（尤其是**完本模式签约评估**、**连载作品首轮与多轮签约评估**以及**AI低质内容治理**）中常见的驳回瓶颈，提供一套经过实战全书重构（138章数十万字级别）检验的工业化文学去AI化调教、审核与重构工作流。

---

## 1. 核心定位与审核模型拆解

番茄小说平台对签约申请（尤其是完本模式签约）采取 **“算法特征初筛 + 人工编辑抽样终审”** 的双层审核漏斗模型。常规大语言模型（如原生 GPT/早期模板化 Prompt）生成的内容极易触发以下一票否决：

### 1.1 平台算法初筛模型的扣分特征
1. **结构假死与未完结判定（“内容没有收尾”）**：
   - 算法通过实体关系图谱与章末信息熵监测终局闭环。若全书在最后 5~10 章未能对开篇立项的核心冲突（如身份鸿沟、初始屈辱、关键情感裂痕、开篇标志性道具）完成双重兑现，而是以平淡流水账或机械口号潦草断尾，会被算法直接打上“内容没有收尾/烂尾”标签。
2. **日历天气模板开篇（高度聚集的 AI 指纹）**：
   - 连续多章以“X月X日清晨/午后，某某地的风霜/阳光/细雨……”开篇，直接被算法判定为批量拼接模板，判定为低质流水账。
3. **解释性负熵与账本审计体（Accounting Prose）**：
   - 角色动辄算账、精细到几厘几分钱的辩解、反复论述“并非……而是……”等二元排他否定，通篇说明文腔调，算法判定其叙事信息密度极低、缺乏故事推进。
4. **格式与编码失范**：
   - 章节标题或正文中残留书名号 `《》`（番茄后台章节标题只填“章节号 章节名”，严禁正文出现书名号）。
   - 残留 Markdown 符号（如 `#`、`**`、`>`、`-`、反引号）。
   - 西欧编码（Latin-1/Windows-1252）错读导致的灾难性中文乱码（如 `ã€` 替代了 `【` 或 `“`）。

### 1.2 人工编辑复核的一票否决项
1. **情绪空转，缺乏即时收益**：主角处处隐忍或纯靠旁白宣布“震惊全场”，读者看不见反派实质损失与主角具体所得（真金白银、契约所有权、身份座次、权力）。
2. **现代职场语域穿帮**：古风、玄幻或民国题材中，角色对话大段充斥“供应链、风险等级、指标核算、流程规范、权限分配、统一调配、观察期”等现代公司语腔。
3. **缺少人间烟火与具象触感**：通篇只有概念推动，没有饭食香气、旧衣补丁、手掌老茧、泥泞冷雨、炉火温度等支撑真实感的细节。

## 2. 五大签约质量闸门（The 5 Signing Quality Gates）

任何需要冲刺签约、重构或改写的小说，必须通过以下五道刚性质量闸门：

```
[源文纯文本] ──> [1. 格式编码门] ──> [2. 去AI恶疾门] ──> [3. 母语语域门] ──> [4. 爽点账单门] ──> [5. 终局收尾门] ──> [签约级正文]
```

---

### 门禁一：纯文本格式与编码硬闸（Zero-Tolerance Format Gate）

| 检验项 | 刚性标准 | 错误示例 | 正确规范 |
| :--- | :--- | :--- | :--- |
| **正文格式** | 纯文本，严禁任何 Markdown | `**他冷笑一声**`、`### 第3章` | 纯中文段落，段首不缩进或使用中文标准全角排版 |
| **书名号禁令** | 正文与章节标题严禁出现 `《》` | `012-读《本草纲目》.md`、`《侍亲规约》` | `012-熟读本草.md`、`侍亲字约` 或 `“侍亲规约”` |
| **文件编码** | 强制 UTF-8 无 BOM，LF 换行 | UTF-8 with BOM、CRLF 混杂 | 严格以 UTF-8 纯文本读写，杜绝 Latin-1 乱码 |
| **单章字数** | **2,050 ~ 3,800** 非换行字符 | 单章 < 1,900 字（短小卡签约）或 > 5,000 字（注水拖沓） | 商业网文黄金体量：**2,400 ~ 3,300 字/章** |
| **章节命名** | 序号与标题纯字，中间用短横或空格 | `第3章 《夜战》 (改).md` | `003-夜战青龙.md` |

---

### 门禁二：破除四大 AI 恶疾（Anti-AI Slop Gate）

#### 恶疾 1：账本审计体（Accounting/Auditing Prose）
- **病症**：角色在对白或旁白中大段汇报“先收定钱三百文，买料耗费二百五十文，另拨八文作挑夫脚费，余四十二文按四六开入私匣……”。
- **药方**：**将财务计算转化为具体的动作冲突与神态反应**。不要替读者算账，写银钱压在掌心沉甸甸的铜锈味、破旧布包抖落时的窘迫、铜板敲在柜台上的脆响，以及为了几文钱产生的家庭裂痕与尊严较量。

#### 恶疾 2：日历天气模板句开篇（Calendar-Weather Formula）
- **病症**：每章第一句机械固定为“X月X日清晨/午后，某某街巷的微风/晨霜吹醒了沉睡的瓦屋……”。
- **药方**：**严厉切除，强制使用中途切入法（In Media Res）**！
  - 必须从**人物动作、异常声响、器物碰撞、激烈对白或身体感官**直接开门见山。
  - 时间与节令必须自然化入第二、三句的动作细节中（例如：“袁恪手里的刨花擦过榆木板，发出一声刺耳的脆响。十月廿五的倒春寒顺着门缝灌进来……”）。

#### 恶疾 3：口号式升华与机械完结标签
- **病症**：章末出现“属于他们的时代大幕终于轰然拉开”、“这不仅是一张桌子，更是两代人的硬骨头……”等空洞排比，或在正文最后机械打上 `（全书完）`。
- **药方**：**严禁任何抽象议论文式的升华，删除所有（全书完）标签**。结尾必须收在具象的生活画面、呼吸感或悬念余韵上（例如一盏昏黄的油灯、热气腾腾的一碗面、夫妻对视一眼后的会心一笑）。

#### 恶疾 4：“并非……而是……”等反刍式二元排他否定腔
- **病症**：AI 极度习惯使用“他要的并非金银，而是这世道的一丝公道”、“这并不意味着妥协，而是更加隐秘的潜伏”。
- **药方**：**直接断句，删除否定前置**，只说人物实际做了什么、拿了什么。将心理独白还原为物理动作与冷硬选择。

### 门禁三：中文母语小说语域与现场质感（Register & Scene Gate）

1. **对白密度指标**：
   - 每一章中文双引号对白（`“……”`）至少 **20 对以上**（推荐 28 ~ 45 对）。
   - 杜绝“旁白概括式推进”。如果两个人在谈事，必须写出有来有回的语言试探、潜台词、语气停顿与眼神闪躲，而不是旁白写“两人商议了良久，敲定了计划”。
2. **架空古典与市井语域净化**：
   - 全面禁绝现代行政管理与企业词汇：
     - ❌ 禁用：`指标、方案、供应链、岗位职责、统一调配、权限、流程、试用期、观察期、风险把控`
     - ✅ 替换为：`门规、名册、流水、分例、主事、规矩、立字为凭、契卷、押金、盘账、点货`
3. **物象与触感（接地气的市井细节）**：
   - 每一章至少融入 2 处鲜活的生活质感：冷饭结的油皮、衣衫腋下的补丁、老茧划过木料的沙沙声、茶汤里的粗沫、石板路上的马蹄泥印。

---

### 门禁四：爽点账单与即时收益（Commercial Payoff Ledger Gate）

在动笔重构任何一章前，必须在内心核验“爽点账单”（不写入正文）：

```text
1. 压迫来源：是谁在仗势欺人？（恶霸、刻薄亲族、势利掌柜、高门管家、腐败规矩）
2. 读者期待：读者此时最渴望看到什么被打脸或被揭破？
3. 主角反制：主角利用什么专业技能、契约规约、人性弱点或预伏后手给予反击？（严禁靠天降神明或空口嘴炮）
4. 对手损失：对手实质失去了什么？（当众出丑、赔付真金白银、失去掌管钥匙、名誉扫地）
5. 实在所得：主角与身边人拿到了什么？（现银落袋、关键房契/铺面契约、入座正席、社会地位抬升）
6. 情绪余波：现场旁观者（街坊、伙计、亲眷）的眼神与态度发生何种具体转变？
```

### 门禁五：终局主旨与情感清偿闭环（Ending Resolution Gate —— 专破“内容没有收尾”）

番茄平台判定“内容没有收尾”的最核心病因：**全书开篇埋下的“核心情感债务”与“主旨意象”在结尾被遗忘，主角虽然在事业上成功，但灵魂没有回家**。

#### 终局四大闭环要素（必查）：
1. **主旨意象的终极重现（The Core Object Payoff）**：
   - 如书名或立项围绕“借席/座上人”展开，终局必须出现一场**真正属于主角自己的、堂堂正正的大席**。
   - 若开篇有标志性屈辱道具（如《座上人》中母亲为吃定亲席在竹篮底藏了一双干净新鞋，却被赶下席面未能换上），全书终章必须重现该道具：**在主角自己掌舵的主席上，当着所有贵客亲友的面，亲手为母亲换上那双新鞋，请父母坐上首座主位！**
2. **人际关系的彻底和解或体面退场**：
   - 不允许让关键配角无疾而终。反派或势利亲族（如曾经刻薄的姑母、旧东家）无需大肆诛灭，只需写出其在岁月与因果中的苍老、折服与体面收场。
   - 核心盟友与学徒（如陪伴创业的徒弟）要有堂堂正正的出师成家或独立立业交代。
3. **双重落点闭环**：
   - **物质/事业落点**：主角不再依附任何人，拥有自己的铺面、手艺、字号或立身之本。
   - **精神/家庭落点**：夫妻同心、两代和解、门庭有光，从“借人席面”蜕变为真正的“座上之人”。
4. **终章文学留白与呼吸感**：
   - 最后一章严禁出现“全书完”三个字，严禁作者跳出戏份发表感言。
   - 故事必须收束在一个从容、安静、充满生机与人间温情的日常动作中（例如摆好最后一双碗筷、推开晨光中的门板、炉火上咕嘟翻滚的肉汤）。

## 3. 标准重构与审查工作流（Surgical Rewrite Workflow）

当接手一部需要优化签约的小说时，遵循以下五步闭环流程：

```
[步骤1: 运行全书扫描脚本] 
       │ 自动定位字符数超标、书名号、日历开头、Markdown、弱对白章节
       ▼
[步骤2: 建立全书缺陷矩阵表]
       │ 区分【需彻底重写章节】与【仅需首尾精修章节】
       ▼
[步骤3: 卷轴式并行重构]
       │ 重写旧稿，补足对白冲突，斩断账本体，理顺时间线
       ▼
[步骤4: 全量回归测试]
       │ 运行 audit 脚本，验证 0 Markdown、0 书名号、0 模板开头、0 乱码
       ▼
[步骤5: 生成阅读导出包与最终确认]
```

### 3.1 卷轴式改写三大心法
- **重写旧稿（Rewrite Old Slop）**：对缺乏戏剧张力的 AI 旧稿，不可修修补补，应严格依照章纲事实源，从动作与冲突全新动笔重写。
- **首尾精修（Header/Footer Surgery）**：对剧情合格但开篇带日历天气、结尾带口号的章节，实施微创外科手术：
  - 斩去第一段日历天气，以第二段的冲突动词前置开篇；
  - 斩去最后一段议论文口号，以倒数第二段的动作余味或悬念收束。
- **时间线单向锁死（Timeline Locking）**：防范“时间倒流”灾难。建立日期看板，严密核验相邻章节日期，确保时间单向流淌。

## 4. 自动化质检脚本与规范化命令

在项目根目录或书籍目录中，可直接调用本 skill 内置的自动化质检工具 `scripts/audit_fanqie_quality.py` 进行毫秒级全书诊断：

```bash
# 1. 纯文本质检（扫描指定正文目录，检查字数、Markdown、书名号、日历开头、对白密度、AI词汇）
python scripts/audit_fanqie_quality.py --dir ./books/借席/正文

# 2. 严格模式（任何警告直接视为失败）
python scripts/audit_fanqie_quality.py --dir ./books/借席/正文 --strict

# 3. 检查单章
python scripts/audit_fanqie_quality.py --file ./books/借席/正文/001-旧木生香.md
```

### 脚本核心审查标准字典：
- `CHAR_MIN`: 2050 字符
- `CHAR_MAX`: 4000 字符
- `MIN_DIALOGUE_QUOTES`: 20 对双引号
- `BANNED_MARKDOWN_REGEX`: `^(#{1,6}\s|>\s|[-*+]\s|\*{1,2}|`{1,3})`
- `BANNED_BOOK_MARKS`: `《.*?》`
- `CALENDAR_WEATHER_REGEX`: `^\s*[0-9一二三四五六七八九十百]+月[0-9一二三四五六七八九十]+[日号]?.*?(清晨|一早|午后|傍晚|深夜|微风|寒霜|秋阳|晨雾|雨水)`
- `AI_SLOP_ENDINGS`: `（全书完）|时代大幕|拉开了大幕|这不仅是.*?更是|仰不愧于天`
- `ACCOUNTING_PROSE_REGEX`: `并非.*?而是|不是.*?乃是`

## 5. 跨智能体环境适配指南（Codex & Gemini Compatibility）

- **在 Codex 中**：
  - 本规范可通过 `$fanqie-signing-quality-optimization` 显式触发，或在提及“番茄签约评估”、“完本模式审核”、“去AI味”、“内容没有收尾”时隐式激活。
  - Codex agent 会读取 `agents/openai.yaml` 与本 `SKILL.md`，执行精准代码与文本手术。
- **在 Gemini (Antigravity) 中**：
  - 支持直接加载到 `.gemini/antigravity/skills/`，通过自然语言或 `/plan`、`/goal` 调度，搭配原生 subagent 协同推进分卷审查。
- **在离线环境或任意外部项目中**：
  - 只要将本目录完整复制到项目的 `.skills/` 或本地知识库中，任何具备基础上下文阅读能力的大模型均可按上述准则实施严格的番茄签约级品控。
