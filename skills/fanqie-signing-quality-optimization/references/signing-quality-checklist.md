# 番茄小说签约质量评估自查核验清单（Signing Quality Checklist）

本清单用于番茄小说申请签约前（尤其是完本模式签约、连载首轮签约评估或驳回后二审复活）的逐章与全书快速质检。

---

## 一、硬性排版与格式自查（一票否决项）

- [ ] **1. 全书零书名号**：正文及所有章节标题中不存在任何书名号 `《》`。
- [ ] **2. 全书零 Markdown 语法**：正文中无 `#` 标题、无 `**` 加粗、无 `*` 斜体、无 `>` 引用块、无 `-` 列表符、无行内代码或代码块。
- [ ] **3. 字符数达标**：每章纯文本非换行字符数严控在 **2,050 ~ 3,800** 字区间，全书无低于 2,000 字的短章，无超过 4,500 字的臃肿章。
- [ ] **4. 纯净 UTF-8 编码**：文件无 BOM，行尾统一为 LF（`\n`），无任何西欧编码错读字符（如 `ã€`、`â€` 等乱码）。
- [ ] **5. 章节命名标准**：章节文件名与平台录入格式为 `NNN-章节名`，无书名号、无作者说明、无版本备注后缀。

---

## 二、去 AI 恶疾与文学质感自查

- [ ] **6. 零日历天气开头**：章节开篇第一句不是“X月X日清晨/午后，天气……”公式；全书每一章直接以**动作、声响、器物、冲突或对白**切入。
- [ ] **7. 零口号升华结尾**：章末无“属于他们的时代拉开大幕”、“这不仅是……更是……”等空洞议论；正文无 `（全书完）` 机械标签。
- [ ] **8. 斩断“账本审计体”**：角色无通篇流水账算账汇报，银钱数额转化为物理动作（铜板砸在柜台、布包勒紧掌心、找零推让）。
- [ ] **9. 根治排他否定腔**：通篇无密集的“并非……而是……”、“不是……乃是……”等反刍说明句，叙事以人物冷硬行动与选择为主。
- [ ] **10. 对白密度充沛**：每章双引号对白（`“……”`）至少达到 **20 对**（建议 28 ~ 45 对），拒绝干瘪的旁白概括。
- [ ] **11. 语域时代纯正**：架空古风/传统世情小说中绝无现代企业行政词汇（如：供应链、指标、权限、流程、方案、统一调配）。
- [ ] **12. 具象生活肌理**：每章具备真实感官物象（饮食冷热、衣物布料、手茧伤口、泥水寒风、器物磕碰声）。

---

## 三、商业爽点与戏剧张力自查

- [ ] **13. 压迫与反制清晰**：本章主角面临的刁难或门槛清晰，反制手段依靠自身手艺、预伏契书或规则博弈，而非空洞嘴炮。
- [ ] **14. 收益与损失兑现**：对手有具体而切实的损失（丢面子、破财、失权、认错）；主角或亲近之人有明确所得（银钱落袋、权益巩固、座次提升）。
- [ ] **15. 节奏起伏合理**：蓄势章有实质信息增量与伏笔落点；高潮章有充分压迫酝酿与反转爆发，不强造廉价震惊。

---

## 四、终局收尾与主旨闭环自查（专克“内容没有收尾”）

- [ ] **16. 开篇核心意象终极呼应**：书名或首卷的核心道具/概念（如“借来的席面”、“压在篮底的新布鞋”）在全书终章完成闭环重现。
- [ ] **17. 核心家庭/情感创伤清偿**：开篇受委屈或产生裂痕的关键亲人（如母亲、父亲、伴侣），在终章获得最深沉的情感慰藉与堂堂正正的地位认可。
- [ ] **18. 终局双重立足点达成**：
  - 物质立足点：主角手艺自成一家，拥有自主商号/独立门户/名望地位，摆脱寄人篱下。
  - 精神立足点：实现自我救赎与两代和解，成为真正意义上的“座上之人”。
- [ ] **19. 配角命运闭环**：昔日刻薄亲友或反派有自然的岁月归宿，忠诚学徒与伙伴有明确的出师与前程交代。
- [ ] **20. 终章静水流深**：最后一章收束在沉静有余味的人间日常中，读者合上书卷时情绪获得彻底饱足与平静。
