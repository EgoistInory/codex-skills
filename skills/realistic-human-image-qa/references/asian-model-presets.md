# Asian Model Presets

Use this file only when a numbered model is explicitly invoked, already bound to the current series, or clearly required for cross-image identity continuity. These profiles are identity anchors, not automatic replacements for people visible in ordinary reference images.

## Activation and fidelity rules

Apply this order:

1. explicit user choice of model number;
2. an existing series binding that the user has not changed;
3. clear profile match plus a real need for identity continuity;
4. otherwise use a reference-derived or generic visible-person description.

When active:

- Keep face shape, native eye size, nose/lip structure, head scale, complexion direction, skeleton, body proportions, muscle state, base hair traits, and temperament stable.
- Let the task reference control outfit, pose, expression, scene, camera, light, and temporary hairstyle unless the user requests a transfer or redesign.
- Do not bind a model from outfit, setting, long hair, or generic Asian appearance alone.
- Do not rewrite the canonical identity after each new reference. Treat makeup, beauty filters, clothing compression, pose, and lens distortion as temporary image conditions.
- Use the concise visual anchor in ordinary prompts. Measurements are calibration ranges for model sheets and drift review, not values that must be repeated in every prompt.
- If a confirmed model sheet or direct identity reference is supplied, it is the strongest identity evidence.
