# 从老款 Model Y 反复纠错中保留的方法

用户提供的历史案例最终收敛为：选对官方模板 → 确定主题、基色和摆布示意 → 按原模板工程化合成 → 单独校准左右部件与文字 → 固定文件规格 → 提供真实下载链接。

| 曾发生的问题 | 下次应如何决策 |
| --- | --- |
| 直接生图让部件数量、轮廓和坐标发生变化 | 用 AI 生成插入素材，最终 UV 由原模板与代码控制 |
| 参考改款 Model Y 或新 Model 3 的布局 | 借鉴图案风格，不借用其他车型的部件映射 |
| 左右车门字母倒置，误用中心对称 | 分别核对每扇门的朝向、位置关系与文字阅读方向 |
| 背景看似黑色而无法判断透明 | 读取 Alpha 并逐像素比较，不能凭预览背景判定 |
| 用截图或口头尺寸代替文件验收 | 重新解码下载文件，检查格式、尺寸、字节数与透明通道 |
| 最后只给文件路径或伪下载地址 | 检查链接对应的文件存在且可下载，然后使用可点击链接 |

历史对话报告过某个工程化成品通过尺寸、体积与 Alpha 校验；这不等于所有后续生成结果通过，更不是实车导入证据。每次最终编辑后都应重新验证实际成品。

车型、主题、金属底色、角色或 IP 的具体选择属于案例，不推广成通用默认要求。本 skill 的固定部分是可重复的制作和验收方法。
